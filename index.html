How it works

Local Docker / Python serves Gradio at port 7860. This page is the entry point; the model runs in the app.

Start the app

Run run.bat or docker compose up --build so Gradio listens on 7860.

Upload or capture

Use a clear dermoscopic photo. Webcam works when the browser allows it.

Read the score

Model returns benign or malignant with a confidence percentage.
